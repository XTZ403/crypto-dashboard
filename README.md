# Крипто-дашборд (ТОП-5)

Пет-проект для практики работы с REST API. Приложение загружает актуальные данные о пяти самых крупных криптовалютах по рыночной капитализации и отображает их в виде карточек.

**Демо:** [https://xtz403.github.io/crypto-dashboard/](https://xtz403.github.io/crypto-dashboard/)

## Стек
* HTML5
* CSS3 (Grid, анимации)
* JavaScript (ES6+, Fetch API, async/await)

## Особенности реализации
* Получение данных с публичного API CoinGecko без использования сторонних библиотек.
* Обработка ошибок сети и некорректных ответов сервера (try/catch, проверка response.ok).
* Показ карточек-заглушек (skeleton) во время загрузки данных.
* Кнопка ручного обновления с коротким звуковым сигналом (Web Audio API).
* Форматирование чисел через Intl.NumberFormat (цены, проценты, капитализация).

## Запуск
Скачать репозиторий и открыть файл `index.html` в браузере.
